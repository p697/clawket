# Native Apple packages

Root instructions apply. These Swift 6 packages support iOS 16.4 and macOS 13; they contain no React Native or JavaScript runtime. Keep the application in `apps/ios`, reusable presentation in `ClawketUI`, and backend identity separate from transport identity.

`ClawketTransport` owns bounded WebSocket frames, RPC correlation, socket generations and transport liveness. Only an adapter's verified backend response may establish readiness or reset retry backoff. Relay ticks prove transport traffic only. Advertise only implemented capabilities; the initial native client supports `relay.client-pong.v1`, not client-ping or transfer hints.

The coordinator owns the single event-stream reader and retry scheduling; screens never compete for that stream. Use the advertised capability list when constructing Relay URLs. Requests may run during handshaking, but neither a successful arbitrary RPC nor `relay.ready` automatically confirms backend readiness.

Retirement synchronously invalidates pending operations before closing the captured socket. Fence every awaited continuation by generation; reject uncertain writes without replay. Cap frames at 8 MiB, JSON nesting at 64, JSON tokens at 250,000 (including object keys) and pending RPCs at 128. The event stream defaults to 256 events/16 MiB of buffered wire data; overflow retires it instead of silently dropping state. Raw frames, endpoint credentials and peer/native error text are application data, never diagnostic labels. Errors describe fixed categories.

Use injectable socket and monotonic clock protocols for deterministic tests. Fixtures in `tests/compat/fixtures/v1` remain the historical protocol source; native tests read them without modifying them. A macOS package test is not evidence of phone, Relay or backend inference behavior. Follow root resource leases and narrow test rules before Swift builds or tests.

Native Upgrade cancellation publishes its fixed closed outcome before cancelling URLSession, whose completion can race synchronously. Normalize errors from a cancelled open to closed, as send/receive do; retain the real stalled-Upgrade cancellation test rather than accepting a generic failure.

`ClawketPairing` preserves the current QR formats, six-digit v2 Box/HMAC exchange, legacy twelve-character SecretBox invitations and Gateway v3 Ed25519 identities. Pin swift-sodium exactly; never substitute a cipher or change proof preimages. Credentials stay in memory until the registry transaction; never put them in diagnostics or navigation. Validate backend/environment before claiming and after receiving credentials, preserve custom Registry QR and local-model/Pi environment exceptions, and never retry a single-use claim.

Pairing HTTP uses cancellable ephemeral requests, no cookies/credentials/cache/redirects, a fifteen-second whole-response deadline and a 128 KiB body cap. QR/plaintext and encrypted invitation fields are bounded to 64 KiB; restricted Relay exchange has a fifteen-second absolute deadline and closes its captured socket on every outcome. Synthetic TweetNaCl vectors in `ClawketPairingTests/Fixtures` derive proof/signature preimages from the current Mobile source; `tests/native-contract/generate-pairing-vectors.mjs --check` verifies drift, with malformed-source regressions alongside it.

`ClawketRuntime` owns one active backend, its transport reader, authentication revisions and retry scheduling. Credential storage is injected through `DeviceCredentialProvider`; storage failures never erase identities or silently grant readiness. Preserve OpenClaw's exact v3 signature, scoped operator/Node tokens, one stale-token repair per unproven recovery and mobile-setup's operator-token handoff. OpenClaw connect errors retain the outer code and interpret only exact known nested auth/pairing/policy codes; unknown codes never grant repair. Only the current saved-device source may clean its captured operator scope once for explicit device-token/scope mismatch. Shared token, bad proof and policy failures never delete credentials. Only a bootstrap-auth INVALID_REQUEST/BAD_REQUEST naming bootstrapToken with an unexpected/invalid-connect schema error and no details.code may disable bootstrap and recycle once to preserved legacy credentials; unrelated/authentication errors never authorize fallback. A new challenge retires old history/RPC work before authenticating again. Direct Hermes requires an ephemeral Upgrade token query from its separate credential; preserve old embedded-token QR records and never substitute that credential for the Relay client token. Hermes validates API health; SDK health validates the exact backend identity. Foreground/path hints request real probes, never manufacture health or replay writes.

The native runtime implements text/history/stop, roster, session creation, negotiated projects/models, typed questions/execution/pair approvals and bounded attachment/artifact APIs. Consent support needs current advertised methods, a real request or a successful supported list; backend identity alone grants nothing. Accept OpenClaw's explicit `allowedDecisions` without inventing missing choices; conflicting choice fields fail closed. Hermes empty approval lists do not prove its opt-in approval capability. Plugin reviews stay preserved without actions until a real resolver contract exists. Full management, native continuation and remaining preservation work stay gated.

Consent operations use coordinator-issued opaque references, scoped to connection/session and exact authentication generation. Stable question draft keys and approval review keys correlate local editing/display copies only, never authorization or diagnostic identities. Never persist action references. Revalidate actual choices, expiry and a single-use thirty-second Always confirmation immediately before dispatch. Dismissal is inert; explicit cancellation may interrupt a native task and stays held until authoritative resolution. No in-flight/unknown write is unlocked by changed list metadata, a timeout or reconnection. Bound request state to 256 records/8 MiB and 1,024 resolution tombstones per authentication; overflow fails closed. Safe list reads cap two concurrent refreshes, eight seconds per route, 128 entries/1 MiB per response. Newer reads and real events fence stale list responses.

Consent milliseconds may be fractional (Hermes forwards finite producer deadlines). Accept only finite nonnegative JS-safe numbers and round down; never extend expiry or invent a missing lifetime.

SDK catalogs are complete frozen snapshots: 64 KiB pages, 10,000 sessions/8 MiB total, at most 512 page reads/90 seconds and one expiry restart. Do not advertise delta/page-index support. Runtime events are a single-reader stream bounded to 64 events/16 MiB. Keep assistant segment identity across tool boundaries and distinguish snapshot text from deltas. Canonical work preserves producer clocks/status, commentary item identity, turn/input lineage and raw review inputs/outputs; unknown status never proves execution. Long native model selection may use a 190-second RPC; the transport request ceiling is 300 seconds, separate from open/handshake limits.

`ClawketUpgrade` stages the current application's legacy installation without modifying its sources. Keep exact legacy credential scope strings separate from normalized endpoints; only imported OpenClaw identities resolve device tokens. Publish a verified manifest only after bounded secret/plain staging and immutable resource copies pass validation/read-back. Consumers activate afterward and retain opaque data until their own migration succeeds. See `Sources/ClawketUpgrade/AGENTS.md` and `../../docs/native-ios/UPGRADE.md`; actual signed same-bundle acceptance remains a separate checkpoint.

`ClawketMedia` owns protected bounded import/preparation, stable resources and generated-file caching; follow its closest instructions and `../../docs/native-ios/MEDIA.md`. Prompt preflight and dispatch use the same full Transport serializer at 8 MiB, with JSON slash behavior matching the existing JS client. Keep input capability/model gates separate from negotiated output support; Relay never falls back to Gateway HTTP tickets. Output handles capture exact authentication/socket ownership, expire and retire on capability loss; unknown writes never replay. Host picker/outbox/preview wiring and device media acceptance remain separate.

# Native Apple packages

Root instructions apply. These Swift 6 packages support iOS 16.4 and macOS 13; they contain no React Native or JavaScript runtime. Keep the application in `apps/ios`, reusable presentation in `ClawketUI`, and backend identity separate from transport identity.

`ClawketTransport` owns bounded WebSocket frames, RPC correlation, socket generations and transport liveness. Only an adapter's verified backend response may establish readiness or reset retry backoff. Relay ticks and nonce echoes prove transport traffic only. Full clients advertise implemented `relay.client-pong.v1`, `relay.client-ping.v1` and `relay.transfer-hint.v1`; only current authenticated Relay negotiation enables the latter two. Keep legacy three-interval ACK expiry separate.

Transfer protection is one absolute ninety-second socket budget, preserved across background and same-socket backend challenges. Actual 128 KiB–8 MiB frames alone can protect a direction; a rejected native send cannot postpone the prior nonce cadence. Cancellation after entering native I/O clears upload grace but preserves the uncertain transfer's budget lock. Complete incoming delivery clears only that direction. A fresh post-latest-transfer nonce may unlock the budget only after all covered native sends and input delivery complete. RPC/handshake/probe waits keep ordinary deadlines unless protected, an absolute max(ordinary,90s) cap and one bounded post-transfer response window; no write replay. Keep Upgrade, bootstrap control and restricted-pairing deadlines independent. See `../../docs/native-ios/LIVENESS.md`.

The coordinator owns the single event-stream reader and retry scheduling; screens never compete for that stream. Use the advertised capability list when constructing Relay URLs. Requests may run during handshaking, but neither a successful arbitrary RPC nor `relay.ready` automatically confirms backend readiness.

Retirement synchronously invalidates pending operations before closing the captured socket. Fence every awaited continuation by generation; reject uncertain writes without replay. Cap frames at 8 MiB, JSON nesting at 64, JSON tokens at 250,000 (including object keys) and pending RPCs at 128. The event stream defaults to 256 events/16 MiB of buffered wire data; overflow retires it instead of silently dropping state. Raw frames, endpoint credentials and peer/native error text are application data, never diagnostic labels. Errors describe fixed categories.

Use injectable socket and monotonic clock protocols for deterministic tests. Fixtures in `tests/compat/fixtures/v1` remain the historical protocol source; native tests read them without modifying them. A macOS package test is not evidence of phone, Relay or backend inference behavior. Follow root resource leases and narrow test rules before Swift builds or tests.

Native Upgrade cancellation publishes its fixed closed outcome before cancelling URLSession, whose completion can race synchronously. Normalize errors from a cancelled open to closed, as send/receive do; retain the real stalled-Upgrade cancellation test rather than accepting a generic failure.

`ClawketPairing` preserves the current QR formats, six-digit v2 Box/HMAC exchange, legacy twelve-character SecretBox invitations and Gateway v3 Ed25519 identities. Pin swift-sodium exactly; never substitute a cipher or change proof preimages. Credentials stay in memory until the registry transaction; never put them in diagnostics or navigation. Validate backend/environment before claiming and after receiving credentials, preserve custom Registry QR and local-model/Pi environment exceptions, and never retry a single-use claim.

Pairing HTTP uses cancellable ephemeral requests, no cookies/credentials/cache/redirects, a fifteen-second whole-response deadline and a 128 KiB body cap. QR/plaintext and encrypted invitation fields are bounded to 64 KiB; restricted Relay exchange has a fifteen-second absolute deadline and closes its captured socket on every outcome. Synthetic TweetNaCl vectors in `ClawketPairingTests/Fixtures` derive proof/signature preimages from the current Mobile source; `tests/native-contract/generate-pairing-vectors.mjs --check` verifies drift, with malformed-source regressions alongside it.

`ClawketRuntime` owns one active backend, its transport reader, authentication revisions and retry scheduling. Credential storage is injected through `DeviceCredentialProvider`; storage failures never erase identities or silently grant readiness. Preserve OpenClaw's exact v3 signature, scoped operator/Node tokens, one stale-token repair per unproven recovery and mobile-setup's operator-token handoff. OpenClaw connect errors retain the outer code and interpret only exact known nested auth/pairing/policy codes; unknown codes never grant repair. Only the current saved-device source may clean its captured operator scope once for explicit device-token/scope mismatch. Shared token, bad proof and policy failures never delete credentials. Only a bootstrap-auth INVALID_REQUEST/BAD_REQUEST naming bootstrapToken with an unexpected/invalid-connect schema error and no details.code may disable bootstrap and recycle once to preserved legacy credentials; unrelated/authentication errors never authorize fallback. A new challenge retires old history/RPC work before authenticating again. Direct Hermes requires an ephemeral Upgrade token query from its separate credential; preserve old embedded-token QR records and never substitute that credential for the Relay client token. Hermes validates API health; SDK health validates the exact backend identity. Foreground/path hints request real probes, never manufacture health or replay writes.

OpenClaw device-approval reviews capture only the public identity actually signed in the current connect scope; exact structured PAIRING_REQUIRED may publish it, peer metadata cannot substitute an identity. A new attempt/ready/disconnect retires it. The public device ID is its public-key fingerprint, never an approval capability or diagnostic identity. See `../../docs/native-ios/DEVICE-APPROVAL.md`.

The native runtime implements text/history/stop, roster, session creation, negotiated projects/models, typed questions/execution/pair approvals and bounded attachment/artifact APIs. Consent support needs current advertised methods, a real request or a successful supported list; backend identity alone grants nothing. Accept OpenClaw's explicit `allowedDecisions` without inventing missing choices; conflicting choice fields fail closed. Hermes empty approval lists do not prove its opt-in approval capability. Plugin reviews stay preserved without actions until a real resolver contract exists. Full management, native continuation and remaining preservation work stay gated.

Consent operations use coordinator-issued opaque references, scoped to connection/session and exact authentication generation. Stable question draft keys and approval review keys correlate local editing/display copies only, never authorization or diagnostic identities. Never persist action references. Revalidate actual choices, expiry and a single-use thirty-second Always confirmation immediately before dispatch. Dismissal is inert; explicit cancellation may interrupt a native task and stays held until authoritative resolution. No in-flight/unknown write is unlocked by changed list metadata, a timeout or reconnection. Bound request state to 256 records/8 MiB and 1,024 resolution tombstones per authentication; overflow fails closed. Safe list reads cap two concurrent refreshes, eight seconds per route, 128 entries/1 MiB per response. Newer reads and real events fence stale list responses.

Reset/delete retire exact-session review references, confirmation tokens, dispatch waits and list workflows before write dispatch; rename/copy/archive grant no physical reset. A latest accepted history head may also retire them only on an actual known-to-known sessionId change, never from nil, pagination, catalog inference or export reads. Keep other routes and connection-wide device/node requests. Old wire IDs remain tombstoned; a proven local non-dispatch permits only a fresh actual pending review with a new reference. Unknown destructive writes keep their route held. Track at most 1,024 exact UTF-8 session contexts per authentication; never evict authority to admit another route. Retirement emits pending-state removal, never fabricated backend resolution.

Consent milliseconds may be fractional (Hermes forwards finite producer deadlines). Accept only finite nonnegative JS-safe numbers and round down; never extend expiry or invent a missing lifetime.

Session management uses nonpersistent current-catalog references, consumed after local validation and revalidated before dispatch. Intersect the declared/negotiated capability with each actual row's permission; SDK native copy/continue does not grant reset/delete. Keep backend-specific source/active-run rules, original project inheritance, archive separate from deletion and unknown writes held without replay. An ACK retires catalog work started while its write was pending, so post-ACK recovery starts a fresh read. Old receipts and history must not mutate a replacement session. See `../../docs/native-ios/MANAGEMENT.md` for the source-backed action and remaining feature inventory.

SDK catalogs are complete frozen snapshots: 64 KiB pages, 10,000 sessions/8 MiB total, at most 512 page reads/90 seconds and one expiry restart. Do not advertise delta/page-index support. Runtime events are a single-reader stream bounded to 64 events/16 MiB. Keep assistant segment identity across tool boundaries and distinguish snapshot text from deltas. Canonical work and its typed history projection preserve producer clocks/status, commentary item identity, turn/input lineage and raw review inputs/outputs. Emit the existing run-start event plus typed start lineage; normalize Gateway terminal tool phases at the adapter boundary. Optional malformed history items do not suppress a usable transcript; exact history-only identities never become live authority. Completion metadata stays a typed accessor on the existing final event; unknown status never proves execution. Long native model selection may use a 190-second RPC; the transport request ceiling is 300 seconds, separate from open/handshake limits.

SDK history tool rows use the shared nested `tool` object (`name`, `callId`, status, input/output and clocks); Gateway top-level tool results remain compatible. `tests/native-contract/sdk-history.mjs --write|--check` generates synthetic vectors through the actual Bridge producers with Node 22.18 or later. Its source-drift and corrupted-input tests belong to the required gate; vectors are not device/inference evidence.
The host may supply an accepted persistent display message ID to history work projection. Use it only for fallback display anchors/items; keep actual tool/run/turn/input lineage unchanged and preserve the existing API default for other consumers.

Message presentation IDs never establish source identity. Preserve explicit producer IDs/provenance, all ambiguous rows, actual physical session IDs and structured transcript positions/boundaries. Compare opaque identity by UTF-8 bytes rather than Swift display-string canonical equivalence. Synthetic IDs, content, clocks and channel names cannot acknowledge local sends. Wire local/owner flags grant no local ownership. Participant display metadata stays bounded, connection/channel/account scoped and credential-free; relative/private avatar URLs never leave the parser. See `../../docs/native-ios/RUNTIME.md` and the participant contract.

Final accessors preserve only actual message metadata and explicit turn/input lineage. Ordinary SDK finals without message IDs remain unknown. Validate structured system terminal notices separately; their legacy assistant compatibility copy must not overwrite a partial reply. A legacy explicit Codex error fallback has no source ID or invented clock. Shared synthetic terminal vectors call the actual pure producer and pin its finish wrapper; never label them phone captures.

Model controls use current-generation opaque references and actual session/model options. Hermes stays global while preserving the caller route; SDK catalog-only reads grant no synthetic conversation. Negotiate Codex speed/permissions with both positive health and actual availability. Permission choices require a revalidated single-use thirty-second confirmation. Keep native pending/unknown settings and real permission requirements across reconnects; missing flags cannot erase a real requirement. A failed settings read alone never blocks chat/Stop. ACK and effective state differ; `/think` preparation is only an ordinary outbox plan. Same-route session mutations retire controls and stale thinking observations without clearing holds. Revalidate images against current model evidence in the runtime actor; image dispatch reservations and model writes must not overtake each other. See `../../docs/native-ios/MODEL-CONTROLS.md`.

`ClawketUpgrade` stages the current application's legacy installation without modifying its sources. Keep exact legacy credential scope strings separate from normalized endpoints; only imported OpenClaw identities resolve device tokens. Publish a verified manifest only after bounded secret/plain staging and immutable resource copies pass validation/read-back. Consumers activate afterward and retain opaque data until their own migration succeeds. See `Sources/ClawketUpgrade/AGENTS.md` and `../../docs/native-ios/UPGRADE.md`; actual signed same-bundle acceptance remains a separate checkpoint.

`ClawketMedia` owns protected bounded import/preparation, stable resources and generated-file caching; follow its closest instructions and `../../docs/native-ios/MEDIA.md`. Prompt preflight and dispatch use the same full Transport serializer at 8 MiB, with JSON slash behavior matching the existing JS client. Keep input capability/model gates separate from negotiated output support; Relay never falls back to Gateway HTTP tickets. Output handles capture exact authentication/socket ownership, expire and retire on capability loss; unknown writes never replay. Host picker/outbox/preview wiring lives in `apps/ios`; physical-device media acceptance remains separate.

`ClawketSpeech` preserves the existing signed Worker contract and native16k PCM converter. Follow its closest instructions and `../../docs/native-ios/VOICE.md`. Capture is explicit and local-first, with no idle audio session; bounded protected recovery survives cancellation/background/failure. Only pre-ready busy retries, never accepted audio or lost results. Keep absolute monotonic evidence deadlines and UTF-16 result bounds. Tests use injected capture; real microphone/cloud acceptance is separate.

Portable history reads use `exportHistorySnapshot`: bounded caller-owned RPCs with cancellation, current scope and existing backend/capability rules. Do not join UI history tasks or publish model/thinking observations from export. Saved/physical storage and entitlement binding live in the iOS host; see `../../docs/native-ios/HISTORY.md`.
Roster Agent main/default evidence stays optional on legacy caches. Preserve the actual OpenClaw default ID, explicit SDK `isMain` or known single-Agent adapter fact; never infer access from a display name or main-session spelling. Local pins inherit host entitlement decisions, not backend identity. See `../../docs/native-ios/ROSTER.md`.

Artifact cache keys may include a local history epoch, which never enters an RPC. Preserve decoding of legacy keys with no epoch, exact UTF-8 scopes, unchanged logical-session quotas and the 24-hour generated-output policy; a reused artifact ID after a physical reset cannot reuse another epoch's cached bytes.
`ClawketCommerce` owns SDK-independent access/plan policy and protected one-time allowance storage; follow its closest instructions and `../../docs/native-ios/PRO.md`. App caches cannot grant paid access. The iOS host alone configures the exact purchase SDK after identity resolution.

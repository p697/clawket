# Native iOS application

Root instructions apply. This maintained SwiftUI application targets iOS 16.4 and later. Reusable native code lives in `packages/apple`; this host owns app lifecycle, permissions, persistence, entitlement integration and presentation binding. Do not embed React Native, JavaScript or a web shell to implement the interface.

The development bundle is `com.p697.clawket.nativeqa`. It installs beside the store app. Keep signing teams, profiles and operator credentials out of project files. Local development builds are allowed; signed distribution archives, uploads and releases require explicit owner authorization.

Read `docs/native-ios/PLAN.md`, `RESEARCH.md` and `PARITY.md` before extending product behavior. Keep missing capability rows pending until actual adapter, persistence and device evidence exists. Presentation actions must have real handlers or remain unavailable. Preview fixtures never supply the shipping composition.

Use WebDriver for the owner's USB test phone; verify its USB serial against CoreDevice wired transport before each session. Do not use a wireless personal phone, iPhone Mirroring, or an app name alone as device identity. Keep identifiers and captured personal screens in ignored local evidence. Follow simulator, iOS and heavy leases; place DerivedData on the configured worktree SSD.

The QA sandbox cannot prove an in-place store upgrade. A future same-bundle importer must validate and preserve Expo Keychain identity/tokens, the connection registry, AsyncStorage, chats, drafts, purchases and extension data before marking migration complete. Empty native preferences never authorize deleting legacy data or generating a replacement device identity.

The app owns main-bundle `Localizable.xcstrings` and `InfoPlist.xcstrings`; see `docs/native-ios/LOCALIZATION.md` for coverage and producer rules. Localize fixed app text with literal resources at its producer. Keep user/backend messages, names, commands, models and paths verbatim; never turn arbitrary presentation strings into localization keys. Maintain actual translations in all 19 supported languages, including camera/local-network permission purposes. CI verifies source coverage and exact values in the compiled app; device rendering, language switching, RTL and linguistic acceptance remain separate parity checks.

Keep the outbox separate from the composer draft. Editing an undispatched local message first holds that exact item; saving preserves its identity and never dispatches. Sent, uncertain and remote messages are immutable through queue actions. Reserve sending synchronously before spawning its persistence/send task. Fence delayed host writes and read results by captured activation and readiness revisions, including A to B to A switches and disconnect/reconnect during persistence. Local draft edits may remain available offline without granting wire authority. Refresh the roster after each newly authenticated ready state, including the first connection.

The host binds questions and approvals through `NativeTaskRequests`, never raw wire IDs. Map actual option values, synchronously preserve edits, and persist bounded local draft values only. Freeze a runtime reference/token before presenting Always, synchronously consume its unique confirmation ID before any await, and invalidate it on scope or review replacement. Keep disconnected reviews inert; stable local review/draft keys correlate display copies only. Safe list reads never prove readiness or resolution; uncertain actions cannot retry from metadata updates. See `docs/native-ios/CONSENT-UI.md` for restore, submission and acceptance boundaries.

`NativeTaskJournal` owns the bounded protected work/review cache; see `docs/native-ios/WORK-JOURNAL.md`. Persist independent render IDs and inert review values only, never Runtime references, decisions or confirmations. Join exact nonconflicting producer lineage; ambiguous late events cannot choose a run. Preserve producer clocks separately from phone observations, recover nonterminal state as unknown, and never mark a tool complete from a run final. Fresh Runtime requests alone restore action authority.

Computer-side device approval is distinct from rejected authentication. Show only the runtime’s current signed-identity review, revalidate its context/connection before copying or retrying, and never approve from the waiting sheet. Dismissal is inert; only verified connect readiness completes it. See `docs/native-ios/DEVICE-APPROVAL.md`.

Media flows go through `NativeAppMedia`/`NativeMediaController`, never view-owned RPCs or persisted provider URLs. Stage provider files inside their callbacks, fence imports and dismissals by picker identity plus route/activation/selection, and keep composer and outbox resource ownership separate. Journal before adoption; retain pending files on unknown save/send outcomes and reclaim only after a serialized union of current/rollback conversation references. Remote artifact metadata is display context, never reusable authority. Preview only bounded safe pixels; SVG/HTML remain files. A created-but-never-presented share releases on dismantle; a presented share retains through system completion, and Photos saving owns an independent lease. See `docs/native-ios/MEDIA.md`.

Session management obtains current references for the selected review only. Freeze destructive confirmations, synchronously reserve exact writes, validate captured receipts and require a post-ACK catalog read before display effects. Keep unknown outcomes locked without replay. Preserve the composer draft and hold the outbox before destructive changes; never delete a whole local conversation or journal from an ACK. See `docs/native-ios/SESSION-UI.md` for typed host outcomes and physical-session reconciliation boundaries.

Conversation titles are display-only: preserve explicit backend names verbatim, replace only exact current session key/native-ID fallbacks with a bounded human-message/preview snippet, then a localized default. Hide only whitespace-only tool rows without media from the transcript projection after journal reduction; retain original cached rows and work metadata.

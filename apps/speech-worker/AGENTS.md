# Speech service

Independent Alibaba Cloud transcription service; never add speech secrets or traffic to Relay/Registry. Audio and transcripts stay in memory and must never be logged or persisted. Only bounded anonymous admission counters may persist. Verify signed device requests, reject replays, and reserve the full recording allowance before contacting the provider. Provider errors expose only stable error codes. Keep provider model/endpoint server-controlled and credentials in Worker secrets. Future paid admission belongs at this server boundary; a client Pro flag is not authorization.

Production is the isolated `clawket-speech` Worker on the `speech.clawket.ai` Custom Domain with `workers_dev: false`; Preview remains `clawket-speech-preview` on its separate Worker and Durable Object. Deploy with the matching Wrangler config, secret, and admission binding. Keep production mobile builds on `wss://speech.clawket.ai/v1/speech`; never use the Preview `workers.dev` hostname for a store build. The zone's machine-API WAF skip covers only `/health` and `/v1/speech` on this host and must preserve rate limiting.

Tracked Wrangler files are disabled self-hosting templates with placeholder provider/domain values. Actual operator settings belong in ignored `wrangler.local.jsonc` / `wrangler.production.local.jsonc`; select the intended config explicitly for authorized deployment. Never commit provider credentials or operator account IDs. Official mobile endpoint restrictions do not apply to community self-hosted builds.

V2 requests negotiate bounded WebSocket error frames because mobile cannot read rejected-upgrade HTTP bodies; v1 keeps HTTP rejection semantics. Differentiate device occupancy, replay, device/IP/daily quota, provider authorization/throttling and stage timeouts with server-generated request UUIDs and cooldowns. Await device lease release before acknowledging session completion. Keep the 120-second provider ceiling and existing admission budgets; long client recordings use separately admitted segments. Structured logs contain only codes, UUIDs, stages, byte counts and timing; invocation request logging and traces are disabled, with query-string redaction enabled, to avoid storing signature headers/IP addresses.

Audio receive acknowledgements are negotiated only for v2 (`flowControl: ack.v1`); send cumulative accepted PCM bytes and never send new control frames to legacy v1 clients. Mobile must not depend on React Native implementing browser `bufferedAmount`.

Provider upgrade deadlines must be cancellable and cleared when fetch settles. Never leave `AbortSignal.timeout` attached to an upgraded WebSocket: its later abort closes an active recording. Session start, audio-idle, duration and finish deadlines belong to the session lifecycle.

Speech setup uses a 25-second pending device lease, promoted by matching unexpired nonce only after provider upgrade; active sessions retain 150 seconds. Preserve full admission charging/replay proofs and the legacy reserve RPC defaults. Register bounded setup with `waitUntil` before admission, enable request abort signals, and accept authenticated v2 sockets before setup so cancel/close can abort the provider handshake. V1 keeps HTTP rejection semantics. Never send `run-task` after cancellation or lost lease ownership; release retries are bounded and nonce-fenced. Local runtime regressions: `npm run speech:test:integration`.

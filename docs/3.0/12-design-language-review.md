# 设计语言提案与视觉验收

2026-09-06。原生设计语言页与连接流程已获用户确认。全 App 推广计划与待验收范围见 `13-design-rollout.md`；不代表整体工程/性能验收已结束。

## 参考如何落地

- [Grok Bot](https://x.ai/news/designing-grok-bot)：以持续存在的 Agent 和对话组织产品，其他概念按需要出现。对应本轮把后端选择、配对操作分层，保留进阶入口而不在首屏平铺。
- [Linear 的改版过程](https://linear.app/now/how-we-redesigned-the-linear-ui)：用真实环境、浅深色及复杂层级检验设计，细调标签、图标与控件对齐。对应共享布局组件、原生预览和交互状态验收。
- [MyMind](https://mymind.com/)：参考其减少管理负担、让内容自然呈现的方向；不直接搬用内容收藏卡片结构。
- [Apple HIG](https://developer.apple.com/design/human-interface-guidelines)：作为平台行为检查入口。本轮采用左侧返回、安全区、可滚动表单和系统键盘；不声称已覆盖完整 HIG。

## 本轮提案

| 项目 | 规则 |
|---|---|
| 主次 | 每个任务状态有一个主操作。墨色按钮承载主操作，次要入口用轻量文字；强调色留给身份、选择与反馈 |
| 排版 | 保留系统字体与现有字阶。标题 28/34，正文 17/24，辅助文字 15/20；终端命令使用平台等宽字体 |
| 留白 | 页面左右 24；使用 4/8/12/16/24/32 的现有间距。按内容关系分组，不靠空白强行把补充入口推到屏底 |
| 容器 | 导航和选择行不加悬浮阴影；输入与命令采用平面底色；圆角服务于控件形态 |
| 导航 | 返回在左，右侧只容纳独立动作。连接页不混排其他后端；返回选择层清空旧配对码 |
| 状态 | 禁用、处理中、错误分开呈现；提交收起键盘；错误保留输入；复制后出现勾选反馈 |
| 复用 | 使用真实通用组件构成样例。页面不复制按钮、选择行、导航和命令块样式 |

## 可操作入口

- 连接页右上角调色盘：打开设计语言页；此入口仅用于本轮审阅，推广前移入开发者入口。
- 设计语言页：组件、主题、基础三个分类；可切换浅深色/强调色、编辑输入、操作开关和弹层。
- “查看连接页示范”：使用同一个连接页面组件，回调隔离，不实际发起连接。输入后连接可查看示范错误。
- 设置 → 开发者 → Design System 现在路由至真实设计语言页；原先该组件只有导出，没有可达路由。

## 第二轮：验收反馈细调

中文占位字距：旧构建中“搜索组件”占位态明显拉开，输入同文案后正常、清空后再次拉开；配对页面返回后仍可复现。文案无空格。原生实现会把默认文字属性复制到 attributedPlaceholder，普通字距未指定时不输出 NSKern。通用输入、弹层输入、粘贴输入现共用显式 `letterSpacing: 0` 默认值，调用方的配对码加宽仍可覆盖。新 Release 构建实测配对页往返、输入与清空，占位态保持正常。未修改 UIKit 或输入法组合态逻辑。

后续光学校正：Hermes 网站素材内置黑色矩形框，已换为官方 App 的 `apps/desktop/public/apple-touch-icon.png`，保留其透明安全区和自带圆角，取消二次裁切。iOS 单行 `FormTextInput` 去除强制段落行高，多行及 Android 保留原行距。对同一滚动位置的 3× 模拟器原图测量，两个样例（Clawket / 需要注意）字形包围框相对输入框中心均从向下 6 像素（2 pt）变为 0；这只说明当前样例，不代表所有字体的光学中心。另实看浅深色、中英文混排、光标和占位文字。

- 三个平台改用官方项目素材，由 `PlatformMark` 统一显示；出处记录在 `apps/mobile/assets/brands/SOURCES.md`。
- 小号主题 Tab 增加 4 点内边距，选中胶囊高 36 点，外层与触控区域保持 44 点。
- 输入错误样例取消红色描边，使用下方的小提示图标与纠错文字；恢复性断网采用中性色横幅和明确的重试入口。
- 开关样例改用白色滑块与中性色轨道；移除假关闭/重新挂载的初始化逻辑，保留原生状态和切换动画。其他消费者的强调色外观仍待推广确认。
- 页头/工具栏用纯图标；独立操作用浅灰底圆形；主操作使用强对比。禁用的浅底圆按钮保留底色、减弱图标，避免轮廓消失。设计语言页第 06 组并排展示这些用法。

验证：iPhone 17 / iOS 26.5 Release 实际查看浅深色 Tab、输入错误/断网、开关开闭、图标操作和弹层；正式连接回调未改动。自动门禁通过 228 套 Mobile 测试 / 2,080 项测试；末次禁用态细调后针对性复测 5 套 / 51 项。视觉检查发现新增翻译放错命名空间，已移动到页面实际使用的 config，并重新打包检查。此轮仍是设计语言审阅，不是全 App 视觉迁移验收。

# 3.0 体验复核与方向建议

日期：2026-09-06。基于 `release/3.0` / `4b0ec9d`，与 `main` 比较涉及 979 个文件。

本文件先记录改动前的研究基线，再记录当前实施与验收状态。用户随后明确要求完整落地，授权推翻旧工程、产品与视觉决策；研究-only、旧规格冻结及“不操作模拟器”的限制已被本次授权取代。数据安全、客户端兼容及后端隔离仍保留。当前实施尚未完成全部人工界面验收。

## 改动前的实测基线

- iPhone 17 / iOS 26.5 模拟器构建、安装、启动成功。使用当前 Debug 构建及已有 Metro 服务，体验了中文首启、后端选择和扫码入口。不能据此评价 Release 性能。
- 读取本机真实 OpenClaw `agents.list` 和 `sessions.list`，确认 Lucy 与 Codex UI Operator；没有向 Lucy 发送测试消息，没有修改其人格、文件或任务。
- 执行 Clawket 本机诊断。`clawket pair --help` 没有帮助分支，实际执行了多后端配对：OpenClaw 刷新了配对二维码，服务保持运行；Hermes 启动失败。此次配对在用户已授权的测试范围内，但帮助参数有副作用本身应修复。
- 当前 Production 配对只输出旧二维码，没有安全邀请或六位码；首启表单仅接受 OpenClaw 六位数字，扫描页没有照片导入控件。尚未查明 Production 邀请失败是旧服务、网络还是其他原因，不将它直接归因为某个服务版本。
- Hermes 源码目录存在，但 Clawket-owned bridge 日志为 `spawn hermes ENOENT`，本机可执行命令缺失，bridge 健康等待超时。尚未安装/更新 Hermes，也未将其视为可用后端。
- 模拟器 Safari 跳转 `clawket://config` 的系统确认框无法由当前 UI 自动化操作：AX 只暴露 sheet，坐标点击返回 `noWindowsAvailable`；已请求用户点“打开”。因此尚未在 App 内完成配对、聊天或设置子页遍历。
- YouMind 邮箱登录与真实聊天尚未执行。三后端端到端、长连接稳定性、Release 性能及六语言逐页验收均未完成。

## 本轮采用的产品方向

定位改为“随时和你的 Agent 接着聊，需要时管理它”。保留 Agent 首页和无底部 Tab 的简单路径，先不增加新看板。

1. **聊天是默认工作面。** 头像与名字进入 Agent 资料；独立、可发现的会话按钮打开历史会话。模型和思考选项收进输入框附近的小入口，不长期占一整行。草图中的“自动”表示跟随后端支持的默认设置，不新增未经支持的协议枚举。
2. **状态要能指导下一步。** 正常时安静；工作时显示一行真实动作，点开看细节；异常时显示失败环节与重试。缓存消息和草稿始终保留，骨架不得无限显示。不用历史任务总数制造 `99+` 焦虑，需要处理的事项应可直接定位。
3. **Agent settings 改为 Agent 资料。** 身份、继续聊天、个性与记忆、定时任务、技能、文件与成果；模型服务商、费用、工具、权限、渠道、配置、日志归入高级管理。能力保持完整，按后端能力呈现。连接入口显示名称与状态，并可看出它同时影响哪些 Agent。
4. **设置首屏缩为五组入口。** 顶部紧凑会员状态，下面“我的连接、外观、聊天与通知、帮助与反馈、关于”。恢复购买进入会员详情；主题/强调色/图标归入外观；开发诊断不混在普通设置里。
5. **连接维护可随时到达。** Agent 状态/资料、异常提示和设置都指向同一个连接页。页面明确提供“重新连接”“暂停此连接/恢复连接”“移除此连接”，不要求用户用删除配对代替临时断开。
6. **视觉上减少悬浮装饰，增强层次。** 缩小头像色块的压迫感，保留 Lucy 自己的头像和人格；主要使用稳定的顶栏、柔和中性色和少量淡紫色。弱化每个按钮的大面积阴影，用字重、间距、内容密度与状态反馈建立重点。中文、德文长文本允许合理换行，不能靠统一单行截断维持整齐。

Grok Bot 值得借鉴的是持久身份、可感知的工作状态和按需展开细节。其文章还强调将可操作结果放回对话中，而不是为每个技术概念创建一个管理入口。参考：[官方设计文章](https://x.ai/news/designing-grok-bot)、[官方产品页](https://x.ai/bot)。搜索得到的部分移动图片实际属于普通 Grok 或 X Chat，本次未将其当作 Grok Bot 的设计证据。

## 推进与验收

用户已授权直接实施上述方向，无需再次确认草图。修复顺序：会话身份/聊天启动 → 弹层/导航 → 连接生命周期与本机后端准备 → Release 性能 → 页面简化及本地化。

每项工程修复先加入能失败的针对性回归，再跑对应 workspace 与 required 门禁。协议/连接改动同时验证 OpenClaw 与 Hermes；服务部署前必须 compat 全绿。

真实验收包括：三后端首连、发消息、流式回复、中止、历史、支持的附件；切换两个 OpenClaw Agent 及多个后端；前后台、断网/恢复、Bridge 重启、主动暂停/恢复；所有可见设置行可进入；中文/英文完整链路，其余四语言长文案、深色与大字；Release 冷/热启动、页面点击与过渡、键盘、长列表滚动。使用重复测量和基线比较，不把 Debug 或草图的流畅度当作最终性能结论。


## 当前实施记录

- 首启拆为品牌欢迎与实际配对两步；账号设置收为五类入口；Agent 资料聚合身份与常用能力，高级管理保留原有功能。连接管理提供明确的暂停、恢复、重新连接和移除动作。
- Agent 高级管理先完成弹层关闭再进入子页；连接高级信息只保留当前连接，避免重复生命周期入口。暂停后的聊天提示明确显示恢复连接。
- 修复 OpenClaw 主会话别名、跨 Agent 首帧历史污染、聊天页头部遮挡、弹层上下文与首开/关闭生命周期。会话列表改为虚拟列表；模型状态刷新合并重复请求；发送后定位最新消息，底部附近跟随增量。停止操作直接中止当前运行。
- 发送失败显示可理解的提示并恢复空草稿，保护新输入；本地缓存分页不再重新引入已被服务器确认的乐观消息。YouMind 的运行 ID 在 task/generation/message 事件间保持不变。
- OpenClaw 与 Hermes Relay 的 Durable Object 休眠恢复现在保留活动客户端路由；心跳调度不再被持续流量不断后推。握手更新不会覆盖刚写入的活动路由标记。两种后端均有丢弃内存后恢复的回归测试。
- Hermes 官方当前安装位于 `~/.local/share/hermes-agent`，版本 0.21.0；旧源码只读保留。Clawket 统一发现新旧路径和可执行命令，处理 spawn 失败，使用稳定且隔离的 API 认证，使用受保护的 `/v1/models` 验证就绪。运行中的 API 拒绝凭据时不自动替换进程。
- YouMind 使用其签名原生客户端所要求的结构化 User-Agent，并明确保留 Clawket 身份。已通过 App 请求验证码、Gmail 获取本次验证码及 App 登录，没有绕过验证或修改服务端。
- 配对粘贴支持旧 OpenClaw 12 字符加密码及链接；非法/超长输入不再通过丢字符和截断变成另一个有效码。二维码图片导入回到原有安全 claim 路径。
- 原生崩溃日志确认 ExpoModulesCore 权限表并发写入导致内存错误。增加三处共享访问同步补丁，两条安装路径均执行，包含缺失/损坏输入与幂等验证；已重新生成原生项目并构建。
